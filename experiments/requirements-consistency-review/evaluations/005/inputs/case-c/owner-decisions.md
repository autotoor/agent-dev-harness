# Recorded Owner Decisions

## Promised Member Surface

Members must have a view of their own loans after checkout and return. Minimum visible loan information has not been selected; do not infer it from the stored fields. The owner will select it with the UI specification before implementing this surface.

## Presentation And Deferred Capabilities

Treat a separate overdue badge as optional pending mock review, not a required feature. Waitlists and notifications are not part of the first release. Do not require either before delivering the loan view or state transitions.
