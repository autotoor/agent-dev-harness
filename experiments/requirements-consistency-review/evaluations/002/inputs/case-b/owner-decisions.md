# Recorded Owner Decisions

## Accepted Component Direction

Owner-approved direction: React for the web client and Postgres for persistence. Backend framework, physical schema, and hosting remain open. Mobile delivery comes later.

## Accepted Behavior

Requests can have no deadline and multiple assignees. Pending items remain in a separate queue after active-list expiry. The queue is display-only initially; owner-facing resolution controls come later.

## Change Authority

Changing selected components requires a new owner decision. None has been recorded. Do not weaken selected direction to an unchosen suggestion or choose replacement technologies during documentation review.
